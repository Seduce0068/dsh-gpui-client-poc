## 検出項目の統一フォーマット

各ラウンドの成果物では、各項目を次の構造で記録する:

- `id`: 短い slug
- `title`: 見出し
- `category`: 残タスク / 機能追加案 / 改善 / 調査必要
- `evidence`: ファイル:行 または 出典 URL、あるいは明示した推論
- `description`: 何が欠けている/提案か
- `value`: 価値・根拠
- `confidence`: high / medium / low
- `known_in_readme`: README に記載済みか (yes/no)
